## MODIFIED Requirements

### UI-009 Effect Stackの表示形態

**変更前:** Effect Stackはワークスペース内に幅200pxのパネルとして表示し、Previewに余裕がある場合はインライン（Previewの上）、狭い場合は「レイヤー・ヒストグラム」から開閉するスクロール領域へ表示する。パネルの折りたたみとColor Histogramとの位置交換ボタンを持つ。

**変更後:** Effect Stackは、左のプロパティパネルとPreviewの間に常設する「Layers」カラムとして表示し、Previewの上に重ねない。

- カラム幅は全レイヤー名（最長`Distort Chroma`）が省略されずに収まる固定幅216pxとする。行の高さは現行の38pxを維持し、Timelineを閉じた1440×900では15レイヤーをスクロールなしに表示する。収まらない場合はヘッダーを固定したままカラム内を縦スクロールする。
- 各行はドラッグハンドル、レイヤー名、状態、ON／OFFトグルで構成する（現行どおり）。
- ヘッダーの折りたたみボタンでカラムを幅48pxのアイコンレールへ切り替えられる。切り替え時はカラムの幅を滑らかに変化させ、内容をフェードインする（視差効果を減らす設定では即時）。レールは各レイヤーの略号、有効状態、選択状態を示し、全レイヤー名をツールチップとアクセシブルネームで提供する。レールの行をクリックするとそのレイヤーを選択し、Altクリックでソロにし、ドラッグで順序を並べ替える。
- Timelineの開閉、Previewの高さはカラムの表示方法を変えない。
- 位置交換ボタンは表示しない。
- Tauri版の別ウインドウボタン、別ウインドウでの操作同期は現行どおりとする。別ウインドウ表示中、メインウインドウのLayersカラムは表示せず、その幅をPreviewへ返す。別ウインドウを閉じるとカラムを元の表示方法へ戻す。

**変更理由:** Previewの上に重ねると効果の確認領域を隠し、Preview寸法による表示切替でレイヤー一覧の所在が不安定になるため。

### LAYOUT-002 パネルの表示

**変更前:** Workspace root幅1000px以上では左右をdock表示し、未満ではPreviewの上に開閉式overlayを表示する。

**変更後:** Workspace root幅1000px以上では、左から「Layersカラム、左プロパティパネル、Preview、右パネル」の順にdock表示する。未満では左右パネルを従来どおり開閉式overlayで表示し、左overlayパネルの上部に「レイヤー／プロパティ」の切替を置いて、同じ領域でレイヤー一覧とプロパティを行き来できるようにする。Previewの「レイヤーを開く」ボタンはレイヤー一覧を、上部モジュールのclickはプロパティを開く。レイヤー名のclickでプロパティへ切り替わり、並べ替えのドラッグ中は一覧を表示したままにする。そのほかのoverlayの開閉、focus、inert、Escapeの挙動は現行どおりとする。

**変更理由:** 1000px未満でもPreviewを覆うdrawerを使わずに全レイヤーへ到達するため。

### LAYOUT-003 表示領域の確保

**変更前:** dockの最低幅は各240px、Preview最低幅は360px。希望幅が収まらないときは最低幅を超える部分だけを比例縮小する。

**変更後:** 左右dockの最低幅とPreview最低幅、比例縮小、Timeline高さの規則は現行どおりとする。dock表示ではLayersカラム（展開時216px、レール時48px）を幅の予算に含める。Previewが最低幅を確保できない場合は、左右パネルを縮小する前にLayersカラムを自動的にレールへ切り替える。自動切替は利用者の展開／折りたたみの希望値を変更せず、幅が戻れば希望値の表示へ戻す。

**変更理由:** Layersカラムの追加後もPreview最低幅を守り、狭い幅での縮小順を一意にするため。

### LAYOUT-004 Preview内のツール

**変更前:** Previewが幅640px未満または高さ560px未満の場合、Effect StackとHistogramは「レイヤー・ヒストグラム」から開閉するスクロール領域へ表示する。余裕がある場合はinline配置と位置交換を使う。

**変更後:** Previewの上には編集ツールを重ねない（Previewの操作ガイドとハンドルを除く）。Effect StackはUI-009のLayersカラムに表示する。Color Histogramは既定で表示しない。設定でHistogramを有効にした場合は、右パネル内の折りたたみ可能なセクションとして表示する。Histogramが無効の間はPreview Canvasの読み戻しによる集計を行わない。「レイヤー・ヒストグラム」の開閉領域と位置交換は廃止する。

**変更理由:** Previewの確認領域を確保し、常時表示の必要がないHistogramの描画・読み戻しの負荷を既定で避けるため。
