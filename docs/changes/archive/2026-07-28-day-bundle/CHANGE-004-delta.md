# Delta

## ADDED Requirements

### GRAD-009 選択肢の結果プレビュー

GradientRampのColor ModeとInterpの選択肢は、現在の色ストップと不透明度を基に、候補を適用した場合の色のつながりを小さなパレットとして表示する。Color Mode候補では既存の選択時と同じ既定補間（色相系はNear、それ以外はEase）を使用し、Interp候補では現在のColor Modeを維持して候補補間を使用する。プレビューは選択操作前の視覚情報であり、候補を選択するまで状態を変更しない。

### GRAD-010 プレビュー常時表示切替

GradientRampは、Color Mode／Interpの選択肢プレビューを常時表示する状態をボタンで切り替えられる。常時表示を無効にした状態では従来のホバー／クリックで開く選択UIを維持し、状態は保存形式へ含めない。

### GRAD-011 配色理論パレット生成

Color Palette Generatorは、tweeqのInputColorで指定した基準色1色から、類似色（Analogous）、補色（Complementary）、分割補色（Split Complementary）、トライアド（Triad）、スクエア（Square）、複合色（Compound）、シェード（Shades）、モノクロマティック（Monochromatic）を生成する。補色では基準色に対する追加1色、トライアドでは追加2色を生成するなど、基準色を含む完成候補を実際の色チップと連続パレットで表示する。候補名や説明文の一覧を主表示にせず、ユーザーが色そのものを比較して判断できるようにする。色数、Hex文字列、詳細な色調整値の入力は求めない。各色のHexは色チップから確認・コピーでき、候補全体をGradientの色ストップへ適用できる。計算はローカルで完結し、配色候補の選択や基準色の変更だけではGradient状態を変更しない。

## MODIFIED Requirements

### GRAD-001 対応するグラデーションとRamp

Rampの選択UIは、色空間と補間方式の候補を適用前に比較できる補助プレビューを提供する。プレビュー表示はRampの保存値、ストップID、色変換、補間計算の契約を変更しない。

### UI表示補助

右サイドバーの「グラデーションワークスペース」と「01 / 主要設定」の補助見出しは表示しない。キャンバスサイズ、GradientRamp、その他の設定ラベルと操作は維持する。

### アイコン描画

共通`Icon`のdeleteアイコンは、蓋・本体・縦線を含む閉じたゴミ箱形状として描画する。`IconButton`のサイズ、`aria-label`、title、操作イベントは変更しない。

## REMOVED Requirements

なし。既存のホバー／クリックによる選択操作は維持します。
