# Delta

## ADDED Requirements

### GRAD-013 GradientRampの操作順序

GradientRampは、グラデーションタイプの直後に色・不透明度ストップの編集ランプとストップ操作を表示し、その後にカラーモード／補間と候補プレビュー、その他の設定を表示します。候補プレビューの展開・縮小によって、頻繁に操作するストップ編集の位置を入れ替えたり、編集を無効化したりしません。

## MODIFIED Requirements

### GRAD-009 Ramp候補の結果プレビュー

SHOW PREVIEWSが有効な場合、Color Mode／Interpは通常のセレクトトリガーとホバー展開を表示せず、候補グリッド上のボタンを選択面として表示します。候補ボタンを押すと対応するColor ModeまたはInterpを適用し、無効時は従来のセレクト操作を維持します。候補の実色背景、前面ラベル、既存のプレビュー計算は維持します。

### GRAD-010 Rampプレビューの常時表示

常時表示の候補グリッドは、表示するだけでなく直接選択できる操作面とします。プレビュー状態は保存せず、グリッドを使わない状態では通常のホバー／クリック選択UIへ戻ります。

### GRAD-011 配色補助パレット

Color Palette Generatorの配色ルールも、基準色から生成した各ルールの実色パレットを候補グリッドとして一覧表示します。候補ボタンの選択は配色ルールだけを変更し、基準色の変更に応じて候補プレビューを更新します。配色ルール名は既存の日本語ラベルを維持し、GradientRampの補間方式名は`Near`、`Far`、`Clockwise`、`Counter-Clockwise`等の英語名を維持します。

### UI-005 プレビュー付き選択肢のラベル

常時プレビューをグリッド表示するCustomSelectは、明示的なプレビュー専用モードが有効な場合にセレクトトリガーとドロップダウンを表示せず、グリッド上の候補ボタンだけを操作面とします。通常のCustomSelect利用箇所には影響させません。
