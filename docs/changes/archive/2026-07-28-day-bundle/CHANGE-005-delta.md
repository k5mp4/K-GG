## MODIFIED Requirements

### GRAD-009 選択肢の結果プレビュー

Color Mode／Interpの各選択肢は、現在のRampを候補設定で評価した色帯を、ブラウザーが有効と解釈できるCSS背景として表示する。透明度用チェッカーは色帯と分離した背景レイヤーまたは有効な背景サイズ指定で描画し、候補が黒一色へフォールバックしない。色帯は文字の左側だけへ置かず、選択肢ボタンの背面全体へ敷く。ラベルと開閉矢印は前面へ置き、候補名を読めるコントラストを確保する。

### GRAD-010 プレビュー常時表示切替

常時表示の候補グリッドも、ホバー選択肢と同じく色帯を文字の背面全体へ敷く。候補を選択する操作、保存値、既定のホバー／クリック動作は維持する。

### GRAD-011 配色理論パレット生成

Color Palette Generatorは、画像からのストップ生成と配色補助を内部の明示的な別区分として表示する。親の説明文は、画像抽出と基準色からの配色候補の両方を説明する。配色補助の基準色・配色ルール・色チップは既存の動作を維持する。

### GRAD-012 配色補助説明のコントラスト

配色補助の説明文、補助ラベル、境界、フォーカス状態は、配置される背景色を基準にWCAG 2.2の1.4.3通常テキスト4.5:1以上、非テキストの識別境界3:1以上を満たす配色を使用する。確認対象は配色補助の区分に限定し、他の既存テーマ色を一括変更しない。
