# Tasks

IssueまたはPRのchecklistだけでは追跡できない作業分解がある場合だけ、このファイルを残します。

- [ ] 現行仕様と関連ADRを確認する
- [ ] `proposal.md` と必要な差分文書をレビュー・承認する
- [ ] 必要なら `design.md` を確定する
- [ ] 実装する
- [ ] 受け入れ条件ごとのテストまたは再現可能な確認を追加する
- [ ] 必要なら`validation.md`へChange固有の結果を記録する
- [ ] 必要ならCurrent Spec/ADRへ意味的な変更を統合する
- [ ] `npm run change:check`後に変更仕様をArchiveへ移動する
