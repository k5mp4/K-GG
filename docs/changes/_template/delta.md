# Delta

現行仕様の全文を書き直さず、この変更で追加・変更・削除する要件だけを記載します。既存要件を変更する場合は安定した要件IDを明示します。

Current Specの観測可能な契約を変更しない場合は、このファイルを作成しません。

## ADDED Requirements

### AREA-XXX 追加要件

変更後の観測可能な動作、境界条件、互換性を記載します。

## MODIFIED Requirements

### AREA-XXX 既存要件の変更

変更前と変更後、変更理由を記載します。

## REMOVED Requirements

### AREA-XXX 廃止要件

廃止理由、代替要件、既存データへの影響を記載します。削除ではなく廃止を表す場合は、現行仕様に後継または `deprecated` を残します。
