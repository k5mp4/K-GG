# Delta

## ADDED Requirements

### EFFECT-010 主スタック順序のランダム化

Effect Stackは、ユーザー操作により主スタックの既知9種類をランダムな順序へ並べ替えられる。結果は9種類を一度ずつ含む順列とし、各レイヤーの`enabled`値、レイヤー設定、選択中の種類、固定段の状態を変更しない。ランダム化の開始時は現在の順序・状態による描画結果を遷移元として保持し、ランダム化後の順序による描画結果へ既定400msの`easeInOut`で表示ブレンドする。遷移中は順序の突然の切り替えを起こさず、完了後に新しい順序を確定する。遷移状態はPreset、thumbnail、exportへ保存・持ち越ししない。

### EFFECT-011 Altクリックによるソロレイヤー

主スタックのレイヤー行またはオンオフToggleをAltクリックしたとき、クリックしたレイヤーを選択し、主スタックの同レイヤーだけを`enabled: true`、その他を`enabled: false`にする。最初のソロ化時に現在の主スタックの有効状態を一時保存し、同じ対象をもう一度Altクリックするとソロ化前へ復元する。ソロ中に別レイヤーをAltクリックした場合は対象だけを切り替え、最初のスナップショットを維持する。ソロ化によって新たに無効化されたレイヤーは、状態欄へ黄色の`STAY`を表示して一時非表示であることを示す。固定段およびレイヤー設定値は変更しない。ソロ状態は既存の`enabled`値としてPresetへ保存され、専用の`solo`フィールドを持たない。

### UI-008 Effect Stack探索操作

Effect Stackのヘッダーまたは既存のスタック操作領域に、主スタック順序をランダム化する操作を表示する。操作名とツールチップは日本語・英語で提供する。主スタック行はAltキーを押しながらクリックするとソロ化できることを利用者へ示す。Altキーなしの行クリック、トグル、ドラッグ操作は既存仕様を維持する。

## MODIFIED Requirements

### EFFECT-002 有効化と順序

既存の手動並べ替えに加えて、ユーザーが明示的にランダム化操作を実行した場合は、主スタック9種類の順序をランダムな順列へ変更できる。有効状態と選択状態は順序変更から独立して保持する。

ランダム化操作は現在の描画結果から新しい順序の描画結果へ一回限りの滑らかな表示遷移を行う。遷移中は同じ操作を一時的に無効化し、完了後にのみ新しい順序を確定する。
