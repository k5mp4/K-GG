# Delta

## ADDED Requirements

### VJ-001〜VJ-007 VJ演奏

[CURRENT-VJ-PERFORMANCE](../../../specs/current/vj-performance.md)を追加する。設定による270pxレイアウト、演奏リストと次候補、BPMの4拍切替、出力寸法固定、scalarパラメータの完全／範囲内ランダム、ロックと範囲編集、static trackへの引継ぎと復帰、アプリ設定の保存を定義する。

## MODIFIED Requirements

### LAYOUT-001 サイズの範囲

640×480論理pxは通常エディターの最小サイズと明記する。VJの640×270論理pxと復帰動作はVJ-001を参照する。通常の幅320pxからのページ横スクロール抑止は維持する。

### PRESET-008 映像への適用失敗

通常・VJで既存document actionsによる正規化を完了してから一度だけ映像へ反映する。壊れた入れ子データの正規化が失敗した場合、現在の映像を部分変更しない。

### VJ-002・003・004・007 追加要求の統合

保存済みフォルダの対象解決・子孫包含・ライブラリ更新への追従と、カスタムリストの保持を追加。演奏対象の全件を事前にCPU／GPU準備し、自動開始の条件に全件準備完了を加える。切替を同期適用へ変更し、拍境界を描画フレームごとに確認する。準備状態・GPU contextの失効と旧Presetのlive値の引継ぎを定義する。

### PERF-011 演奏対象の準備と保持

VJの全件準備ではanalytic Generator variantも対象にし、選択集合のNoise variantを巡回中は通常LRUから解放しない。対象変更・退出で保持を解除する。演奏対象以外の通常アイドル準備を演奏中だけ停止し、退出後に再開する。context lossで中断したコンパイルをShader失敗や準備完了と扱わない。描画式と保存形式は維持する。

### 追加Direct request: VJ-001・003・007

エフェクト欄は有効なlayerのみの8列表示と数値／range操作へ変更する。自動の次候補へ範囲内ランダムを事前適用し、同じPresetの再登場でも新しく準備する。手動読み込み、元のPreset保存値、出力寸法を維持する。未準備の拍境界では映像を維持して停止する。復帰用のtrackは元のPresetから保持する。
