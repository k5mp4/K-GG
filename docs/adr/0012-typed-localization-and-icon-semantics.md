# ADR-0012: 型付き辞書と意味的アイコンをUI表記の基盤とする

## コンテキスト

画面内の英日混在と操作表現の不統一を解消し、ブラウザ、Tauri、分離ウィンドウで同じ表示名称とアクセシビリティを維持する必要がある。

## 判断

- 外部i18n依存を追加せず、英語をキー型の基準とする日英辞書と`LanguageProvider`を実装する。
- 表示言語はUI設定として`kgg.ui-language`へ保存し、プリセットや描画設定から分離する。
- コード上の辞書を実表示の一次情報、開発者向けUI用語集を設計・レビューの規範とする。
- 共通操作は意味ごとの内蔵SVGアイコンと`IconButton`を使い、tooltipとアクセシブル名を同じ翻訳キーから得る。
- 固有名・標準略語を除き、エフェクト名とパラメータ名も表示言語へ翻訳する。

## 代替案

- 外部i18nフレームワークは二言語の現在規模に対して依存と抽象化が大きいため採用しない。
- CSSやブラウザ自動翻訳へ委ねる案は、aria、通知、エラー、別ウィンドウを一貫して制御できないため採用しない。
- 全操作をアイコンだけにする案は、主要操作や曖昧な概念の理解を損なうため採用しない。

## 結果

新しい可視文字列とアイコン操作は辞書、用語集、アクセシビリティ属性の更新を伴う。辞書のキー一致とプレースホルダー整合を自動テストする。
