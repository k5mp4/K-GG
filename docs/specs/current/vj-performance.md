# VJレイアウトとプリセット演奏

## 目的

既存のプリセットとEffect Stackを使い、限られた画面高さで映像を切り替えて演奏する。

## 現在の要件

### VJ-001 レイアウトの選択

初回起動は通常エディターを表示する。設定の「レイアウト」からVJを選択でき、VJの「エディターに戻る」で通常表示へ戻れる。選択はアプリ設定として保持する。表示切替で編集ドキュメント、出力解像度、プレビューのcanvasを作り直さない。

VJの操作領域は高さ270 CSS pxを基本とし、Main、Next／After Next、演奏リスト、横スクロールするエフェクト列を表示する。幅640pxでは操作領域内部を横スクロールでき、上部のBPM・自動切替・復帰操作は表示を保つ。各エフェクトは詳細を開いて全パラメータと範囲設定へ到達できる。TauriのVJ最小サイズは640×270論理pxとし、切替前のウインドウ寸法と最大化状態を復帰時に戻す。

エフェクト欄はEffect Stackで有効なものだけを順序どおりに表示する。1920px幅では8列を同時に表示でき、9件以上は横スクロールする。数値は数値入力とスライダーの両方で調整できる。小さい画面では列の操作幅を維持して横スクロールする。

### VJ-002 演奏リストと手動切替

組み込み・保存済みプリセットを演奏リストへ追加し、順序変更・削除できる。名前をクリックして直接読み込み、前・次ボタンでも切り替えられる。Nextは次ボタンと自動切替が実際に選ぶ候補、After Nextはその後の候補を示す。サムネイルは静止画であり、未読み込み候補の完全なGPU描画を保証しない。

「演奏対象」からK-GG内の保存済みプリセットのルートまたはフォルダを選ぶと、その範囲の保存順で巡回する。子フォルダを含めるか選べる。組み込みプリセットや範囲外の保存済みプリセットは混ぜない。ライブラリ内で移動・削除・追加された場合は対象を更新する。フォルダ選択中は一覧を直接並べ替えず、カスタムリストへ戻すと以前のリストを復元する。空または削除済みフォルダは空の演奏対象となる。

順送りはリスト順に巡回する。シャッフルは各巡回内で重複しない候補を作り、2件以上の場合は巡回境界で同じプリセットを連続しない。2件以上の演奏リストでは巡回末尾でもNext／After Nextを表示し、表示済みの候補を消費する。直接選択やリスト編集は候補列を再構築する。失われたプリセットIDは演奏対象から除く。VJへ入り直す際は通常画面での編集を引き継ぎ、古いVJのプリセットIDを現在表示として扱わない。

### VJ-003 4拍ごとの自動切替

BPMは1〜999、初期値120とする。開始から4拍終了するたびに次候補を読み込む。120 BPMなら2秒間隔。編集用Timelineの再生・停止から独立する。実行中のBPM変更は拍の進行率を維持する。手動切替は拍の位相をリセットしない。

自動切替は、次候補の元のPresetへ現在の範囲内ランダム設定を適用した結果を事前準備して読み込む。Presetで有効なエフェクトだけを対象とし、ロック・範囲・許可候補を守る。範囲設定や次候補の変更で再準備し、巡回で同じPresetへ戻る場合も新しくランダム化する。手動読み込みは元のPresetを使う。サムネイルは元のPresetの静止画を表示する。

自動開始は次のランダム候補のCPU／GPU準備完了も必要とする。読み込み直後から次の候補を準備し、4拍の境界では準備済みの結果を一度だけ同期反映する。境界までに準備が終わらなかった場合は現在の映像を維持して自動切替を停止し、準備失敗を表示する。

演奏対象が2件未満、または全件の事前準備が完了していない場合は自動切替を開始できない。拍境界は描画フレームごとに確認する。停止・VJ終了・再起動後は手動状態となる。対象やGPUコンテキストが変わって準備が必要になると自動切替を停止し、再準備後に利用者が開始する。VJ退出後に準備結果を映像へ適用しない。バックグラウンドの遅延で複数区間を逃しても復帰時は1回だけ切り替え、連続読み込みを発生させない。

### VJ-004 読み込みと出力

通常エディターと共通のPreset正規化・適用処理を使う。演奏対象の全件についてドキュメントのclone・正規化と、必要なShaderのコンパイルを事前に行う。準備中の件数と失敗を状態欄へ表示し、失敗時は事前ロードを再試行できる。準備済みの手動候補は全件完了を待たずに使える。準備は現在の映像を変更しない。

準備済みの切替は同期的に一度だけstoreへ反映し、GPU準備待ち、変位マップのclone、ドキュメント全体の再正規化を切替時に行わない。既存GPUコンテキストでanalytic Generatorを含む必要なShaderを準備し、演奏対象が使うNoise variantを巡回中に保持する。VJ退出・対象変更では不要な保持を解除する。旧Presetの省略項目と現在のPreview Loop／BPM／easingは適用時のlive値を引き継ぐ。引き継ぐモードや外部入力により準備済みと異なるShaderが必要になった場合は、映像を維持して再準備する。

VJ演奏中は演奏対象以外の通常バックグラウンドShader準備を停止し、退出時に再開する。実行中のコンパイルは中断しない。GPUコンテキストを失った場合はその準備結果を無効にし、復旧後のコンテキストで再準備する。失効によるコンパイル中断をShaderのコンパイル失敗や準備完了として通知しない。

有効なGlassが読み込み時の効果量でidentityとなる場合や、Blurが0の場合も、アニメーション・live操作で後から必要になるProgramを事前準備する。WebGLが利用できない場合は準備失敗を表示し、準備済みとして扱わない。

正規化が失敗した壊れた入れ子データで現在の映像を部分変更しない。VJではプリセット内のresolutionを適用せず、現在の出力サイズを維持する。ライブラリ内のデータを直接編集しない。GPUコンテキストの消失・復旧時は準備状態を無効にし、同じコンテキストで準備完了した候補だけを適用する。実際の描画時間はGPUとシーン負荷に依存し、絶対的な0msのフレーム時間を保証しない。

### VJ-005 パラメータのランダム化

「完全ランダム」と「範囲内ランダム」を提供する。対象は有効な全エフェクトまたは選択中の1エフェクト。Effect Stackの種類・順序・ON/OFFはランダム化しない。

数値は正規の上下限とstepに収める。enumと真偽値は合法な候補から選び、色はHEX色として扱う。モード変更で有効になる項目も対象にする。外部画像・動画・モデルを必要とするモードを未ロードのままランダムに選ばない。曲線、変位マップ、外部素材、プリセット名や保存先は対象外。

### VJ-006 範囲とロック

各項目のロックは両方のランダム化から除外する。範囲内ランダムでは数値min/max、enum・真偽値の許可候補、色パレットを指定できる。数値範囲は正規の範囲と交差させ、stepに合う値がない場合は変更をスキップする。空の許可候補・色パレットもスキップする。

未設定項目は現在値の周囲±20%の正規範囲幅を初期数値範囲とし、enum・真偽値・色は現在値を初期候補とする。モードや真偽値の変更で新しく現れる項目も初期範囲を用いる。「現在値の周囲に設定」で範囲を更新できる。「全範囲に戻す」でロックを保ったまま制限を解除する。既に編集した範囲はプリセット切替をまたいで保持する。モード候補の新しい上下限でロックまたはスキップする値を保持できない場合、その候補を選ばない。

### VJ-007 演奏操作の復帰と保持

VJで手動編集またはランダム化したパラメータだけをstatic trackへ切り替え、既存キーフレームによる上書きを止める。触れていないパラメータのアニメーションは維持する。「プリセットのアニメーションを戻す」で演奏開始／読み込み時のtrackへ復帰する。

自動読み込みの範囲内ランダムも変更したパラメータだけをstatic化する。アニメーションの復帰には元のPresetのtrackを用いる。「読み込み時の値に戻す」は読み込んだランダム化済みの値を基準とする。

「ランダム化を戻す」は直前のランダム化前の値とtrackを戻す。「読み込み時の値に戻す」は演奏開始／直近読み込み時の値とtrackを戻し、現在のEffect StackのON/OFF・順序を保つ。VJ退出だけでは演奏中に変更した値を巻き戻さない。

レイアウト、BPM、カスタム演奏リストID、対象種別、フォルダID、子フォルダの包含、順序・シャッフル、範囲・ロックはアプリ設定へ保存する。実行中状態・現在の候補列・一時復帰用スナップショット・事前準備キャッシュは保存しない。Preset形式は変更しない。
